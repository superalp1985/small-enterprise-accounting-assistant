# 一人公司行业模板调研

复核日期：2026-07-17

## 结论

行业模板不等同于工商登记行业，也不替代税务资格判断。模板只解决三个问题：

1. 首次建账时隐藏明显无关的一级科目，降低选择负担。
2. 给出常见业务、建议明细科目和月末检查重点。
3. 提醒容易混用个人账户、平台结算款、预收款和无票成本的场景。

首批一人公司细分模板为：

| 模板 | 典型经营模式 | 主要账务特征 |
| --- | --- | --- |
| 咨询与专业服务 | 顾问、设计外包、翻译、项目服务 | 合同/验收确认收入，预收款、外包成本和股东垫付款较多 |
| 软件与信息技术 | 软件开发、SaaS、运维、技术支持 | 云资源、软件订阅、研发支出、无形资产和订阅期间收入 |
| 电商与网络零售 | 网店、直播电商、平台批零 | 库存、在途商品、平台待结算款、退款、佣金和推广费 |
| 内容创作与广告设计 | 视频博主、自媒体、直播带货、摄影、品牌内容 | 平台销售/佣金/商单/激励、待结算款、扣费投流、合作方分成和器材折旧 |
| 本地维修与安装服务 | 设备维修、维护、弱电安装、上门服务 | 配件耗材、工具、预收款、完工确认收入和临时用工 |

原有服务业、商贸业、制造业、建筑业、农林牧渔业模板继续保留，适合业务已经
较复杂或需要更宽科目范围的企业；“完整66科目”用于迁移账套、专业人员复核和
全科目验收。

## 数据依据

- 国家统计局《第五次全国经济普查公报（第四号）》显示，2023年末批发和零售业
  企业法人单位为1019.7万家，其中货摊、无店铺及其他零售业77.2万家；租赁和
  商务服务业企业法人单位457.3万家，其中商务服务业占88.8%。
- 同一公报显示，2023年末信息传输、软件和信息技术服务业企业法人单位169.1万家，
  比2018年末增长85.2%。这支持将电商、专业服务和软件信息服务作为首批细分方向。
- 国家统计局《第五次全国经济普查公报（第三号）》显示，制造业和建筑业的科目链条
  明显不同于轻资产服务业，因此继续采用独立综合模板，不强行归入一人公司轻量模板。

## 设计边界

- 所有模板共用唯一的《小企业会计准则》66科目主档，不复制或改名一级科目。
- 切换模板只改变界面默认显示的科目，不删除历史凭证、余额或词库映射。
- 推荐明细科目是建账提示，不会自动替用户确认收入时点、研发资本化或税前扣除资格。
- 内容平台品牌名不直接映射科目；净额结算、退款扣费和代扣税费必须按平台结算单拆分复核。详细口径见[内容平台资金往来语义映射调研](内容平台资金往来语义映射调研.md)。
- 建筑施工、医药、金融、进出口、跨境平台、特许经营等存在许可或特殊税制的业务，
  不属于当前一人公司自动税额测算边界。

## 验收口径

每次发布必须运行隔离的全周期验收：完整66科目分别生成平衡凭证，连续处理12个月，
覆盖普通/红字发票、未开票收入、专票、银行对账、工资个税、固定资产折旧、季度税费
计提及撤销、损益结转及撤销、归档及重新打开、备份恢复、年度所得税准备和30表Excel
导出。验收数据只能写入单独的测试目录，不得复用真实账套。

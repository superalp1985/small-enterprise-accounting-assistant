平台名称、产品名称和规则会变化。本范围用于维护常见语义别名，不代表软件与平台存在合作、授权或接口对接关系。

## 映射口径

| 业务实质 | 建议明细 | 关键控制 |
| --- | --- | --- |
| 平台内已结算但尚未提到企业银行账户 | 1012 其他货币资金-平台待结算款 | 提现仅结转资金科目，不重复确认收入 |
| 公司自营商品通过店铺或直播间销售 | 5001 主营业务收入-平台商品销售 | 按订单及履约资料确认，不按净到账额确认 |
| 为第三方商品带货取得佣金 | 5001 主营业务收入-平台带货佣金 | 与自营商品销售分开，保存佣金结算单 |
| 星图、聚星、蒲公英、花火等品牌商单 | 5001 主营业务收入-内容商业合作 | 按合同、交付验收和含税口径确认 |
| 创作激励、充电、直播打赏等持续经营收益 | 5001 主营业务收入-创作者激励与打赏 | 核对虚拟币换算、平台分成和退款 |
| 平台技术、交易、店铺或结算服务费 | 5601 销售费用-平台技术服务费 | 从收入毛额中单独拆出，不冲成净收入 |
| 千川、DOU+、磁力金牛、聚光、薯条、万相台等投流 | 5601 销售费用-平台推广投流 | 充值余额与实际消耗分开确认 |
| 可退店铺或履约保证金 | 1221 其他应收款-平台保证金 | 扣划、不退或转服务费时按实际性质调整 |
| 平台销售退货退款 | 5001 主营业务收入-平台销售退回 | 同时检查商品是否退回、成本是否需要转回 |
| MCN、主播、达人或联合创作者直接履约分成 | 5401 主营业务成本-内容合作分成 | 核对合同主体、扣除凭证和扣缴义务 |

平台品牌名本身没有唯一会计含义。例如“抖音”可能是销售、佣金、商单、投流、退款或待结算款，不能作为确定性入账规则。软件只把“巨量星图商单收入”“巨量千川投流费”等带有明确业务动作的复合词作为确定性语义；孤立品牌名交由用户补充描述，不自动推荐科目。

平台净额结算、代扣税费、退款同时扣费属于多科目业务。软件必须提示人工拆分并阻止一句话凭证直接入账，不得把银行到账净额直接当作收入。平台显示的代扣税费也不当然等于公司已经完成全部纳税申报。

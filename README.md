# 小企业会计智能记账报税工具

> [!IMPORTANT]
> 本项目源码可查看、修改并允许个人及小企业用于自己的记账报税准备，但禁止
> 闭源商用、收费服务、SaaS 和其他盈利活动。修改版向第三方提供时必须公开完整
> 对应源码。该自定义许可包含非商业限制，属于 source-available，不是 OSI 认证
> 的开源许可证。详见 [LICENSE](LICENSE) 和 [PATENTS.md](PATENTS.md)。

面向个体经营者、一人公司和小企业自身使用的本地记账、票据 OCR、语义科目
推荐、月末结账、税费测算和 Excel 导出工具。项目固定采用《小企业会计准则》，
不与《企业会计准则》或政府会计科目混用。

当前税务自动测算明确只支持“小规模纳税人 + 小型微利企业”。一般纳税人、
非居民企业、核定征收、特殊行业和复杂重组等情形会被资格检查拦截，不自动套用税额。

当前源码版本为 `1.7.4`。自动化测试覆盖账号登录、自然语义匹配、OCR 适配、
66 科目主档、完整 12 个月账务周期、税务期间和 Excel 导出。完整图文教程见
[全周期使用教程](docs/小企业会计智能记账报税工具-全周期使用教程-v1.7.0.docx)。

## 免费辅助定位与责任边界

本项目按本地 ERP 式工作流组织账套、凭证、往来、资产、结账、报表和税务准备，
但产品性质仍是免费、本地优先的记账和财税准备辅助工具，不构成代理记账、纳税
申报、会计、税务、审计或法律服务，也不是电子税务局直接上传模板。OCR、语义
科目推荐、税费测算和导出结果均需用户结合原始凭证、实际业务及主管机关口径复核。
软件不承诺结果准确、合规、适用、可直接申报或被任何申报系统接受。

软件按截至 2026-07-17 复核的现行政策预设常用参数，包括小规模纳税人 1%
增值税测算率、月/季免税销售额参考阈值、小型微利企业 5% 有效测算率及资格
参考上限。相关优惠政策目前标注执行至 2027-12-31。税率、申报频率、免税
阈值、资格上限和政策日期均可在“系统设置 -> 政策与边界”中修改；软件不会
自动保证政策持续有效，申报前仍应以电子税务局和主管机关最终口径为准。

## 主要能力

- 三层词库：明确词和无歧义同义词按规则匹配，口语及冲突词交给本地模型。
- 内容平台语义：覆盖抖音/抖店、快手/快手小店、微信视频号/微信小店、小红书、
  B站和淘宝直播的销售、带货佣金、商单、激励、待结算、扣费、投流、保证金、
  退款及合作方分成；平台品牌名本身不直接入账，净额结算和代扣项目强制拆分复核。
- 科目主档：独立维护《小企业会计准则》完整 66 科目，词库只保存语义映射；
  提供咨询与专业服务、软件与信息技术、电商与网络零售、内容创作与广告设计、
  本地维修与安装服务五个一人公司模板，并保留服务业、商贸业、制造业、建筑业、
  农林牧渔业和完整目录模板。选择模板时会显示常见业务、月末重点和风险提示。
- 一句话记账：从自然语言提取金额、日期和结算方式，模型判断业务科目，
  程序自动生成借贷平衡的凭证预览，确认后才入账。
- 本地模型：Qwen3.5 2B Q4，GPU 优先、CPU 回退、关闭思考模式。
- 本机登录：首次启动必须创建账号和密码，之后每次验证成功才加载账套和本地模型；
  密码以 PBKDF2 加盐摘要保存，主界面可验证当前密码后进行变更。
- 票据处理：RapidOCR 图片/PDF 识别及批量导入，兼容新版数电票分离字段、
  空格税号和多行商品名称，并按发票号码拦截账套内及当前批次的重复票据。
- 批量复核：识别后可搜索、筛选和多选票据，对选中票据统一修改科目、方向、
  摘要和交易双方，支持补录完整票据信息，再选择“入账选中”或“全部确认入账”。
- 操作留痕：所有已保存的单张/批量复核修改记录修改前后值；软件内只读查询和导出，
  SHA-256 哈希链可检测签名日志被外部改写，校验失败时停止新的保存和入账操作。
- 价税与销项：统一含税/不含税换算，支持普通销项、增值税专票、红字发票和
  未开票收入；销项税额自动拆成三条平衡分录。
- 基础账务：期初余额、凭证、银行对账、工资社保、固定资产和折旧。
- 数据安全：SQLite WAL、启动完整性检查、JSON 镜像修复和最近 5 份自动备份。
- 可逆账务：普通凭证支持反过账，损益结转支持撤销，归档期可确认后重新打开。
- 月末处理：归档前强制检查每张凭证借贷平衡，不平凭证会阻止结账并高亮显示。
- 期间控制：可设开账日期，已归档月份默认禁止修改，避免误改历史申报数据。
- 固定资产：按月计算折旧并一键生成借贷平衡的折旧凭证。
- 税务期间：增值税、所得税和印花税分别支持按月/按季期间，内置免税阈值、
  小型微利资格校验、纳税调整和申报期末税费计提/撤销。
- Excel 输出：月度报税准备总览、会小企 01/02/03 财务报表、总账、明细账、
  日记账、66 科目目录、增值税、个税、印花税、所得税预缴、年度汇算准备和申报前校验。
- 发票批量导入：支持税务系统导出的旧版 `.xls`、`.xlsx` 和 `.xlsm` 文件，统一进入复核队列。

## 第一次使用

1. 首次启动先创建本机账号和登录密码；以后每次启动需先完成登录验证。
2. 打开“系统设置”，填写企业名称、统一社会信用代码、纳税人类型和开账日期。
3. 已经营企业在“对账与资产”录入期初余额；新设企业可以使用零期初。
4. 日常小额业务直接在“本月工作台”用一句话记账；发票图片或 PDF 使用
   “票据批量导入”。批量识别后先在待复核列表多选并统一修改，必要时单张补录，
   确认无误后再入账；处理记录可在“操作日志”中查询。
5. 每月导入银行流水并完成对账；有工资或固定资产时生成相应凭证。
6. 在“月结与导出”补录红字/未开票收入、纳税调整和印花税项目；申报期末先
   生成税费计提凭证，再结转损益并导出 Excel 报税准备资料。

导出的 Excel 是根据本地账套形成的记账、对账和报税准备工作底稿，目标是减少
重复整理，但可能仍需补充或调整；它不是全国统一的电子税务局直传文件，也不代表
申报口径、合规性或受理结果已经确认。用户仍需按当期政策、在线表单和主管机关
口径核对并自行完成最终申报。

## 普通用户安装

下载 `小企业会计智能记账报税工具-Setup-<版本>.exe` 后双击安装即可。安装包已包含
Qwen 模型、GPU/CPU 推理组件、RapidOCR 和精简 Python OCR 运行时，不要求安装
Python、执行 `pip install` 或手工下载模型，启动时也不会出现 CMD 黑窗口。

程序默认安装到当前用户的 LocalAppData。账套、备份、日志和 OCR 缓存也保存在
LocalAppData 的独立可写目录，升级或卸载程序文件不会把账套写进安装目录。
账号凭据保存在独立的 `security/credentials.json` 中，不保存明文密码，也不会随
账套 ZIP 恢复而回滚。该登录用于限制软件入口，不等同于磁盘或账套文件加密。

## 源码运行

要求 Windows 10/11、Python 3.10 及以上。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

模型和运行时二进制不进入源码仓库。可将它们放在本项目的 `models/`、
`runtime/` 目录，或者设置：

```powershell
$env:ACCOUNTINGDEMO_MODEL_ROOT = "D:\local-models"
$env:ACCOUNTINGDEMO_RUNTIME_ROOT = "D:\accounting-runtime"
```

环境变量指向相应目录内容的根目录；程序不会依赖固定盘符或用户名。

## 备份与恢复

- 每次启动会先执行 SQLite `PRAGMA integrity_check`，再创建压缩备份并只保留最近 5 份启动备份。
- “存档管理”可手工创建、校验、导入、导出、恢复备份，并可从 SQLite 或 JSON 镜像自动修复账套。
- 恢复、自动修复、反过账和重新打开归档期前都会再创建保护性备份。
- 备份 ZIP 内含 SQLite 一致性快照、JSON 兼容镜像、SHA-256 清单，恢复前会先校验。
- 备份仍建议定期复制到另一块硬盘或可信的加密存储；本机磁盘物理损坏无法靠同盘备份解决。

## 启动与测试

```powershell
.\run.bat
python -m unittest discover -s tests -v
```

完整年度、完整66科目的隔离验收：

```powershell
$env:ACCOUNTINGDEMO_FULL_CYCLE_ROOT = "$PWD\build\full-cycle-manual"
$env:ACCOUNTINGDEMO_FULL_CYCLE_OUTPUT = "$PWD\build\full-cycle-manual.json"
python .\main.py --full-cycle-test
```

该验收会创建唯一的测试账套，连续处理12个月并生成30表Excel，不会写入真实账套。
行业选择依据和模板边界见 `docs/一人公司行业模板调研.md`，内容平台资金活动
的语义口径见 `docs/内容平台资金往来语义映射调研.md`。

生成 Windows 离线安装包：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build_windows_release.ps1
```

构建脚本会从 Python 官网下载并校验固定版本的 CPython 3.12 精简运行时，使用
PyInstaller 生成无控制台窗口的应用目录，依次运行资源冒烟测试和全周期全科目
验收，再由 Inno Setup 生成一个安装程序 EXE。任一验收失败都会停止发布。

数据默认保存到 `data/small_enterprise/`，导出和 OCR 中间文件保存在 `out/`。
这些目录均不进入版本控制。

小企业会计智能记账报税工具 1.7.6 -> 1.7.7 更新补丁

适用范围：仅适用于已安装 1.7.6 正式版的 Windows 64 位用户。

安装方法：
1. 退出正在运行的小企业会计智能记账报税工具。
2. 双击更新补丁 EXE，按提示完成安装。
3. 补丁会校验已安装版本，并原地更新到 1.7.7。

数据安全：
- 补丁不会删除或覆盖账套、账户密码、票据、凭证、导出文件和自动备份。
- 安装前仍建议在软件“存档管理”中执行一次手动备份。
- 若版本不是 1.7.6，请直接使用 1.7.7 完整安装包覆盖安装。

1.7.7 主要更新：
- 修复打包版读取大型平台订单 Excel 时，工作簿解析线程与 Tk/Tcl 冲突造成的程序整体闪退。
- 税务发票和平台订单 Excel 改由独立子进程解析；即使解析器异常，主界面仍可保留并显示中文错误提示。
- 平台订单工作簿在隔离进程内一次性读取并及时释放，降低大文件解析期间的资源与生命周期风险。
- 已使用 1592 行真实平台订单导出文件完成实机测试，1271 张有效订单成功生成 2542 条借贷平衡分录。
- 补丁不会覆盖现有账套数据、账户密码、票据、凭证和备份。

重要提示：
本软件是本地记账和报税资料准备辅助工具，不替代会计、税务专业判断，也不承诺导出资料可直接申报。税率、优惠政策、资格条件和申报口径请以主管税务机关当前规定为准。

小企业会计智能记账报税工具 1.7.5 -> 1.7.6 更新补丁

适用范围：仅适用于已安装 1.7.5 正式版的 Windows 64 位用户。

安装方法：
1. 退出正在运行的小企业会计智能记账报税工具。
2. 双击更新补丁 EXE，按提示完成安装。
3. 补丁会校验已安装版本，并原地更新到 1.7.6。

数据安全：
- 补丁不会删除或覆盖账套、账户密码、票据、凭证、导出文件和自动备份。
- 安装前仍建议在软件“存档管理”中执行一次手动备份。
- 若版本不是 1.7.5，请直接使用 1.7.6 完整安装包覆盖安装。

1.7.6 主要更新：
- 大批量 Excel 在 CPU 机器上先完成解析、规则映射和词库语义桥接，不再逐条调用大上下文模型导致长时间假死。
- 单张或小批量记录仍可使用“重新匹配”调用本地模型进行模糊语义分析。
- 增加 `fatal-crash.log` 和 `thread-crash.log`，无控制台窗口时也能保留进程级诊断信息。
- 保留 1.7.5 的线程安全修复、税务 `.xls/.xlsx/.xlsm` 导入、平台订单导入和批量复核功能。
- 补丁不会覆盖现有账套数据、账户密码、票据、凭证和备份。

重要提示：
本软件是本地记账和报税资料准备辅助工具，不替代会计、税务专业判断，也不承诺导出资料可直接申报。税率、优惠政策、资格条件和申报口径请以主管税务机关当前规定为准。

小企业会计智能记账报税工具 1.7.3 -> 1.7.4 更新补丁

适用范围：仅适用于已安装 1.7.3 正式版的 Windows 64 位用户。

安装方法：
1. 退出正在运行的小企业会计智能记账报税工具。
2. 双击更新补丁 EXE，按提示完成安装。
3. 补丁会校验已安装版本，并原地更新到 1.7.4。

数据安全：
- 补丁不会删除或覆盖账套、账户密码、票据、凭证、导出文件和自动备份。
- 安装前仍建议在软件“存档管理”中执行一次手动备份。
- 若版本不是 1.7.3，请直接使用 1.7.4 完整安装包覆盖安装。

1.7.4 主要更新：
- 支持税务系统导出的旧版 .xls、.xlsx 和 .xlsm 发票文件。
- 批量导入显示读取行数、识别阶段和推荐科目进度，大文件处理期间可持续看到当前进展。
- 避免同一税收分类在模型无结果时反复调用，提升数千张发票的批量导入稳定性。
- 平台订单直接生成销售收入待复核推荐，不再按唯一支付单号逐条调用模型。
- 交易关闭订单继续保留在列表中并阻止入账；交易成功订单进入统一复核队列。
- 保留人工修改科目、批量确认和只读审计日志，补丁不会覆盖现有账套数据。

重要提示：
本软件是本地记账和报税资料准备辅助工具，不替代会计、税务专业判断，也不承诺导出资料可直接申报。税率、优惠政策、资格条件和申报口径请以主管税务机关当前规定为准。
